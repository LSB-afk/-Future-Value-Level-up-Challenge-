# FitHome 첫 화면 구성안

## 화면 목표

첫 화면은 사용자가 복잡한 부동산 정보를 직접 비교하기 전에, 자신의 상황을 간단히 입력하고 바로 매칭을 시작하도록 유도한다.

핵심 인상은 `집을 검색하는 서비스`보다 `내 조건에 맞는 집을 선별해주는 서비스`에 가깝게 잡는다.

## 전체 구조

1. 상단 내비게이션
2. 히어로 배너
3. 조건 입력 카드
4. 추천 탐색 카테고리
5. 주요 기능 카드
6. AI 조건 입력 안내
7. 신뢰 정보 및 데이터 안내

## 1. 상단 내비게이션

### 로고 영역

- 로고: `FitHome`
- 보조 문구: `내 생활에 맞는 집 찾기`

### 메뉴

- 매칭하기
- 전세 위험 점검
- 주변 인프라
- AI Agent

### 우측 버튼

- `관심 단지`
- `시작하기`

## 2. 히어로 배너

### 메인 문구 후보

#### 1안

내 예산과 생활에 맞는 집을  
지도 위에서 바로 비교하세요

#### 2안

출퇴근, 예산, 안전까지  
내 조건에 맞는 집만 골라보세요

#### 3안

좋은 집을 찾는 기준,  
FitHome이 먼저 정리해드립니다

### 서브 문구

월세·전세·매매 조건을 선택하고 목적지를 입력하면, 통근 시간과 주변 인프라, 전세 위험 신호를 함께 비교합니다.

### 히어로 버튼

- `내 조건으로 매칭하기`
- `AI에게 조건 말하기`

### 히어로 보조 정보

- `월세 · 전세 · 매매 지원`
- `실거래가 기반 가격 비교`
- `통근 · 생활 SOC · 안전 점수 반영`

## 3. 조건 입력 카드

스크린샷의 보험 조회 카드처럼 히어로 아래에 떠 있는 형태로 배치한다.

### 카드 제목

내 조건 빠른 입력

### 입력 항목

#### 거래 유형

- 월세
- 전세
- 매매

#### 예산

- 월세 선택 시: `월 주거 예산`
- 전세 선택 시: `전세 예산`
- 매매 선택 시: `매매 예산`

#### 목적지

- 플레이스홀더: `회사, 학교, 자주 가는 장소를 입력하세요`

#### 가구 유형

- 1인 가구
- 신혼
- 자녀 가구
- 노인

### CTA

내 조건으로 매칭하기

### 마이크 버튼 안내 문구

버튼 텍스트: `말로 조건 입력`  
상태 문구: `듣는 중... 어떤 집을 찾고 있는지 자연스럽게 말해주세요.`

## 4. 추천 탐색 카테고리

### 섹션 제목

어떤 기준으로 찾고 있나요?

### 카테고리 버튼

- 출퇴근이 편한 집
- 예산에 맞는 집
- 생활 인프라가 좋은 집
- 전세가 안전한 집
- 가족이 살기 좋은 집
- 조용하고 쾌적한 집

### 선택 시 기대 동작

각 카테고리는 기존 가중치 슬라이더를 자동으로 조정하는 프리셋처럼 사용한다.

예시:

- `출퇴근이 편한 집`: 통근 가중치 증가
- `예산에 맞는 집`: 주거비 가중치 증가
- `생활 인프라가 좋은 집`: 생활 SOC 가중치 증가
- `전세가 안전한 집`: 안전 및 전세 위험 점검 강조

## 5. 주요 기능 카드

### 섹션 제목

FitHome으로 한 번에 확인하세요

### 카드 1. 조건 매칭

제목: 내 조건 기반 매칭  
설명: 예산, 목적지, 가구 유형, 우선순위를 반영해 후보 단지를 추천합니다.

### 카드 2. 지도 비교

제목: 지도 위 후보 비교  
설명: 추천 단지의 위치와 이동 거리, 주변 생활권을 한 화면에서 확인합니다.

### 카드 3. 주변 인프라

제목: 생활 SOC 확인  
설명: 의료, 교육, 교통, 생활편의, 여가 시설 접근성을 비교합니다.

### 카드 4. 전세 위험 점검

제목: 전세 위험 신호 확인  
설명: 가격 수준과 권리관계 확인 항목을 바탕으로 계약 전 체크 포인트를 제공합니다.

### 카드 5. AI Agent

제목: 궁금한 점 바로 질문  
설명: 선택한 아파트를 기준으로 전세 안전성, 가격, 주변 환경을 대화형으로 확인합니다.

## 6. AI 조건 입력 안내

### 안내 바 문구 후보

#### 1안

조건을 고르기 어렵다면, 마이크를 누르고 원하는 집을 말해보세요.

#### 2안

“가격이 저렴하고 병원이 가까운 곳”처럼 말하면 가중치를 자동으로 맞춰드립니다.

#### 3안

출퇴근, 예산, 생활 편의, 안전 중 무엇이 중요한지 자연스럽게 말해주세요.

### 예시 질문

- 가격이 싼 곳이면 좋겠어
- 회사까지 가까운 집을 찾고 싶어
- 병원과 편의점이 주변에 많았으면 좋겠어
- 전세 사기가 걱정돼서 안전한 곳이 좋아
- 골고루 균형적인 곳을 찾고 싶어

## 7. 신뢰 정보 및 데이터 안내

### 섹션 제목

데이터 기준을 투명하게 보여드립니다

### 안내 문구

FitHome은 공공데이터와 지도 기반 정보를 활용해 아파트 후보를 비교합니다. 실거래가, 주변 인프라, 통근 시간, 전세 위험 점검 정보는 제공 기관의 응답 상태에 따라 일부 항목이 제한될 수 있습니다.

### 짧은 고지 문구

추천 결과는 의사결정을 돕기 위한 참고 정보이며, 계약 전 등기부등본과 실제 매물 조건은 반드시 직접 확인해야 합니다.
