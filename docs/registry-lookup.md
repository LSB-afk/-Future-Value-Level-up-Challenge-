# 등기 조회 연결

핏홈 서버는 하이픈 상품 145의 주소 검색과 회원 열람 API를 사용한다. 운영자가 사용할 수 있는 인터넷등기소 계정과 하이픈 상품 이용 권한이 필요하다. 운영 계정의 권한, 건별 요금, 고객에게 결과를 표시·보관할 수 있는 계약 범위를 확인한 후 서버에 연결한다. [하이픈 상품 안내](https://hyphen.im/product/view?seq=145) · [요청·응답 명세](https://hyphen.im/product-api/view?seq=145)

| 서버 환경변수 | 값 |
| --- | --- |
| `HYPHEN_USER_ID` | 하이픈 이용기관 계정의 user-id |
| `HYPHEN_HKEY` | 해당 계정의 Hkey |
| `FITHOME_IROS_USER_ID` | 운영자가 관리하는 인터넷등기소 계정 |
| `FITHOME_IROS_USER_PW` | 해당 인터넷등기소 계정의 암호 |

네 값을 서버 프로세스 환경에 제공한다. 등기 조회가 연결되지 않은 환경에서도 서버에 PyMuPDF 또는 pypdf가 설치되어 있으면 사용자가 제출한 등기사항전부증명서 PDF를 대조할 수 있다. PDF 판독은 격리 모드(`python -I`) 하위 프로세스에서 실행되므로, 사용자 폴더(`~/.local`)가 아니라 서버를 실행하는 인터프리터 환경(가상환경 등)에 설치해야 한다. 이 서버에는 등기 원본 PDF를 저장하지 않는다.

등기 원천 수수료는 2026-11-23 시행 규칙 기준 인터넷 열람 1,100원, 인터넷 발급 1,400원이며, 제공자 사용료는 별도다. [수수료 조문](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1023718353)

주소 검색(`IN0004000168`)과 열람(`IN0004000163`)에는 제공자 계약에 따른 사용료가 발생할 수 있다. 검색 목록에서 현행 건물 또는 집합건물을 고른 후 유료 열람을 확인해야 열람이 요청된다. 집합건물은 매물 주소에 동·호수를 명시하고 검색 결과에서 한 세대로 특정되어야 한다. 주소나 PDF에서 동·호수 또는 유효 권리를 대조할 수 없으면 자동 입력을 보류한다.

제출본은 텍스트가 있는 25쪽·4 MiB 이하 PDF를 지원한다. 열람일, 주소, 부동산 고유번호와 현재 유효한 을구 요약을 대조해 순위번호별 채권최고액을 집계한다. 최근 30일 이내 자료가 기준이며 공동담보·말소·변경·판독 불명 자료는 직접 확인한다. 대조 결과는 PDF 서명·진위 검증이나 실제 대출 잔액 확인을 의미하지 않는다.

유료 주소 검색과 열람은 로컬 개발 시 서버에 직접 연결한 루프백 요청으로 사용할 수 있다. 외부에 공개할 때는 역방향 프록시에서 고객의 로그인과 열람 권한을 검사한다. 프록시는 클라이언트가 보낸 `X-FitHome-Gateway` 헤더를 제거한 후, 서버의 `FITHOME_REGISTRY_GATEWAY_TOKEN` 값과 일치하는 비밀 헤더를 추가해 전달한다. 이 값은 브라우저나 공개 코드에 제공하지 않는다. PDF 제출과 집주인 서류 요청에는 이 헤더가 필요하지 않다.
