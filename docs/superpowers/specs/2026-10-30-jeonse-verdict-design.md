# 전세 안심 판정 리포트 설계 (1단계)

2026-10-30 · 브랜치 `fithome-jeonse-verdict`

## 목표

계약 전 임차인이 "이 집에 보증금을 넣어도 되는가"를 근거와 함께 한 화면에서 판단하게 한다.
K Car 차량 상세의 진단 대시보드(한 줄 요약 → 그림 진단 → 진단 결과 표 → 항목별 기준·실측·결과 → 과거 이력 타임라인)를 참고한다.

최종 목표는 핏홈이 집을 직접 점검하고, 사용자·중개사·이웃의 문제 제보를 실시간으로 받아 반영하는 것이다.
프로토타입은 아직 직접 점검을 하지 못하므로 항목마다 근거 출처를 구분해 표시한다.

| 출처 | 의미 |
|---|---|
| 핏홈 점검 | 핏홈이 직접 확인한 값 (시연용 예시 매물에서만 사용) |
| 등기부 | 사용자가 등기부를 보고 입력한 값 |
| 입력값 | 사용자가 입력한 그 밖의 값 |
| 추정 | 계산이나 추정으로 만든 값 |
| 제보 | 사용자 제보, 미검증 |
| 미확인 | 아직 모르는 값 |

## 범위

포함:
- 판정 엔진 `api/jeonse_verdict.py`와 `POST /api/jeonse-verdict`
- 시연용 예시 매물 3건 `data/jeonse_demo_cases.json` (안심·주의·위험, "시연용 예시"로 표시)
- 문제 제보 저장소 `api/property_feedback.py`와 `GET/POST /api/property-feedback`
- 새 화면 `#verdict` (`app/verdict.js`, `app/verdict.css`), 첫 화면 문구를 전세 판정 중심으로 변경

제외 (다음 단계):
- 등기부 PDF 자동 분석
- 중개사 배지와 매물 등록
- 문자·카톡 실제 발송
- 에이전트 근거 검증 루프

기존 맞춤 추천(`#recommend`)은 "안심 단지 찾기" 보조 기능으로 그대로 둔다.

## 판정 규칙

LTV = (근저당 채권최고액 + 선순위 보증금 + 내 보증금) ÷ 주택가격

주택가격 기준:
- 시세·감정가 직접 입력
- 실거래가
- 공시가격 × 140% (HUG 방식)

추정값이면 "안심" 등급을 줄 수 없다.

기준선:

| 기준선 | 의미 |
|---|---|
| 70% | 주의 시작 (실무 권고) |
| 80% | 깡통전세 실무 경계 (법정 기준 아님) |
| 90% | HUG 전세보증 가입 한도 |

모르는 값은 0으로 계산하되 결과를 "하한"으로 표시하고, 등급은 "주의"를 넘지 못한다.
다가구는 선순위 보증금이 핵심 값이다.

등급:
- **위험**: 다음 중 하나라도 해당
  - 신탁등기, 압류·가압류, 경매, 임차권등기
  - 소유자와 계약 상대 불일치
  - 임대인 체납 있음
  - LTV 90% 초과
- **주의**: 다음 중 하나라도 해당
  - LTV 70~90%
  - 핵심 값 미확인
  - 주택가격이 추정값
  - 소유권 이전 90일 이내
  - 보증금이 공시가격의 126% 초과 (HUG 보증 어려움)
  - 비주거 용도, 위반건축물
  - 보증보험 불가
  - 확인 요청 거절·무응답
  - 등기부 열람 후 30일 경과
  - 미검증 제보 있음
- **안심**: 위 조건에 하나도 해당하지 않고 LTV 70% 미만

## 리포트 화면 (K Car 구조 대응)

1. 등급 + 한 줄 태그 + 핏홈 점검 상태
2. 집값 대비 빚 막대: 근저당, 선순위 보증금, 내 보증금, 여유분과 70·80·90 기준선. 근저당 여유액 표시
3. 주요 판정 결과 표: 권리 진단, 판정 통과·주의·위험·미확인 건수
4. 상세: 권리 진단 탭(항목별 없음·있음·미확인), 판정 항목 탭(기준·이 집 값·결과·출처)
5. 등기 이력 요약과 타임라인(소유권·근저당·제보 필터)
6. 확인 요청: 요청문 복사, 상태 기록(요청 전·요청함·받음·거절·무응답). 기록하면 판정에 반영하고 브라우저에 저장
7. 단계별 재확인: 가계약금 전, 계약 당일, 잔금 직전, 전입 당일
8. 특약 추천: 판정 결과에 따라 문구 선택
9. 문제 제보: 실시간 목록과 제보 양식. 서버 JSON 파일에 저장하고 15초마다 갱신

## 검증

- `python3 api/jeonse_verdict.py`: 등급 규칙 자체 검증(assert)
- 브라우저에서 예시 3건과 직접 입력 판정 흐름 확인, 콘솔 에러 없음 확인
